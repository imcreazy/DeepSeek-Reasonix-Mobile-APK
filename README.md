# Reasonix Mobile (Android)

把电脑版 [Reasonix](https://github.com/esengine/DeepSeek-Reasonix) 装进手机。

> **上游项目：[`esengine/DeepSeek-Reasonix`](https://github.com/esengine/DeepSeek-Reasonix)**
> Reasonix 本体（内核与界面）由上游作者开发维护，版权归 `Copyright (c) 2026 Reasonix Contributors`，
> 以 MIT 许可发布 —— 本仓库的 [LICENSE](LICENSE) 即上游原文，未作改动。
> 本仓库只做安卓侧的封装（把内核与页面打进 APK、补上移动端布局与安卓特有的接线），
> 不含对上游代码的重新授权，也不代表上游。

## 这是什么

需要算力或要动文件时，通过内置的远程连接把它指向你自己的服务器，命令在服务器上执行。

- **本机运行**：应用内自带内核与界面，离线也能启动，不需要额外装一个后台服务。
- **自带远程连接**：内置 SSH，可添加并管理多台服务器，在其上打开工作区、跑任务，
  界面仍在本机。首次连接会在目标机器上引导一个常驻实例。
- **局域网配对**：手机扫电脑上的二维码即可接管那台电脑的会话；扫过一次的电脑会记
  在菜单里，下次点一下就能重连，不用再扫。反过来，电脑也能扫码连上手机上的内核。
- **隐私**：对话、代码与 API Key 都保存在本机应用目录内，不上传。

## 1.3.1 修复（务必用这一版）

修的是手机端自测交回的 1.3.0 报告，主要是内置浏览器：

- **打开网页失败后，之后再打开别的网页都会返回上一次的旧错误** —— 失败状态跨导航没清，而且把「页面还没到」当成了页面本身。现在每次导航都会重新等它落定，并只看当前实际页面；「刷新」重试的是失败的那个地址，不再是错误页自己。
- **点不了、填不了（没有元素编号）** —— 手机版浏览器以前不产生元素编号。现在快照会给能操作的元素编号（如 `[e3]`），点按、填写、下拉选择、滚动都能按编号做，不必再手写脚本。
- **`new_tab` 没反应也没提示** —— 手机只有一个浏览页面，现在会在返回里明说一次。
- **「页面请求」永远显示为空** —— 现在会列出页面实际请求的资源，并注明响应内容在本机拿不到。
- **网页打不开只剩英文错误码** —— 现在按原因显示中文；同时修好了内核语言跟随系统（此前内核一律英文，所以中文提示永远不会出现）。

> 如果你装的是 1.3.0 或更早，请换 1.3.1。

## 1.3.0 修复与新增（务必用这一版）

用户反馈 2 项 + 手机端实测报告里的项。

- **加号加附件，多选后一个都没加进去**（只选一个才行）—— 系统选择器返回多选时，结果放在「多项」字段里，而壳层读的是单文件字段，于是多选读出来等于空。现在先读多项、再回退单文件，并去重。
- **窄屏下 AI 用浏览器会抢占整屏、盖住对话**（增）—— 以前 AI 一调 `browser_open` 界面就自动把浏览器面板推到前面，手机太窄时那等于全屏盖住回答，切回来又被盖。现在窄屏改为在对话上方给一条提示（「模型正在使用浏览器 · 查看 / 知道了」），点了才打开；宽屏仍自动在右侧 dock 显示、不挡对话。新增设置项 **设置 → 内置浏览器 → agent 打开网页时自动显示**，可覆盖宽度判定。
- **网页加载失败只说英文错误页** —— 两层原因：浏览器的错误页本身也是一次加载，把刚报的失败状态清掉；且读页面时把错误页文字当正文抽回。现在壳层识别错误页并把原因交给内核，界面按原因显示中文（如「找不到这个地址。内网域名需要连上公司网络或 VPN 才能解析」）。
- **地址栏/标题与实际页面不同步** —— 页面读完新地址后没通知界面刷新。现在地址或标题一变就通知。
- **`browser_open` 说明与行为不符** —— 说明写「加载并返回快照」，实际返回的是发起那一刻的快照。说明已改成如实描述。

内部：补上内核已有的 `browser.navigation_failed` / `navigation_timeout` / `no_tab` 三条拒绝码的中英文（此前会退回显示英文原文）；改工具描述后同步再生成了 `docs/TOOL_CONTRACT.md` 与 golden `tool_schemas.json`。

> 如果你装的是 1.2.4 或更早，请换 1.3.0。

## 1.2.4 修复（务必用这一版）

只修问题、不加功能。修的是 1.2.3 实测报告里撞上的三件事，其中两件是「以为修好了、其实没生效」：

- **AI 写不进你选的共享工作区**（前三版都没修好）—— 会话的工作目录由壳层设定，而内核判断「能写到哪」是从工作目录自己推的，手机上两者没对上。这一版把工作目录**明说给内核**（内核新增 `--dir`），不再靠推断。
- **内置浏览器仍打不开**（报 `connection refused`）—— 服务确实起来了、端口也确实分配了，但它绑在 IPv6 的 `::1`，而内核连的是 IPv4 的 `127.0.0.1`。根因是一句「取本机回环地址」的调用在安卓上返回 IPv6、在电脑上返回 IPv4，所以电脑上测不出来。现在两边都明确用 `127.0.0.1`。
- **设置 → 网络里的 `dns` / `doh` 在配置文件里找不到** —— 这两项的注释示例只写在「全新生成的配置」里，升级上来的配置保存时只改有变化的行、从不补注释。现在保存过网络设置就会补进 `[network]` 段。

顺带修掉同一处的两个问题：内核先开网页、界面后打开浏览器面板时不再失败（视图改为按需创建）；内核启动与浏览器端口之间不再有先后依赖；工作目录选错时不再静默退回，会记下原因。

> 如果你装的是 1.2.3 或更早，请换 1.2.4。

## 1.2.3 修复与新增

用户截图反馈 4 项 + 内置浏览器 + 从上游捡回一项修复。用户可见的主要有：

- **对话框右上角的「tokens」文字去掉** —— 只留上下箭头与数字；「估算中」的 `≈` 移到数字前，信息不丢。
- **模型来源的名称可以写中文** —— 显示名与配置名分离：界面照你写的显示中文，配置里自动派生一个 ASCII 名（`公司中转站` → `relay`）。
- **探测失败不再显示一串原始 JSON** —— 那串 JSON 是内核协议原文，现在按错误码显示中文句子。
- **设置 → 模型服务页的输入框不再被键盘挡住** —— 上一版只让整张面板避开键盘，输入框所在的滚动区域没跟上。
- **内置浏览器（增）** —— 以前那个浏览器面板用内嵌框架，禁止嵌入的站点（如 Stack Overflow）打不开；现在改用应用自带的 WebView 渲染，这类站点能打开，AI 也能读正文、执行脚本、点击页内元素。
- **用严格的中转站时，回放「无参数工具调用」不再返回 HTTP 400** —— 从上游 2.37 摘回：无参数调用现在发空的 `{}`。

内部还修掉三个真问题：内置浏览器用的本机接口原本**没有认证**（同机任意应用可调用 `/eval`），现已加每次启动生成的随机密钥；浏览器加载失败的提示会被随后的一次「加载完成」抹掉，现已修；页面侧一项静态检查（`actions.test.ts`）被本工程 1.2.0/1.2.2 的改动弄破，现已补登记。

> 如果你装的是 1.2.2 或更早，请换 1.2.3。

## 1.2.2 修复

真机实测反馈 + 手机版 Reasonix 的审查单，共处理 17 项。用户可见的主要有：

- **每个「复制」按钮都说复制失败** —— 安卓 WebView 里页面拿不到剪贴板权限，改走壳层的剪贴板桥。
- **长按文件有时弹菜单、有时变成选文字** —— 文件行不再可选中，系统的文本选择菜单不再抢长按。
- **打开文件后「导出到下载」点不动** —— 那一行的布局把按钮和标签叠在同一格；现在每个区域显式定位。
- **导出 `.md` 变成 `.md.txt`** —— 写文件时声明成 `text/plain` 与 `.md` 不符；现在从扩展名推导类型。
- **加号上传附件默认打开的不是「最近」** —— 1.2.0 起给选择器传了一个「去最近」的参数，但那参数指的目录在系统里并不存在，ROM 回落到「下载内容」。系统默认落点本来就是「最近」，去掉该参数即可。
- **底部报错条的「知道了」仍点不到** —— 它的外层容器自成一个层叠上下文；现在外层一起抬高。
- **键盘弹着时工作区菜单跑到右上角** —— 菜单改用可见区域（`visualViewport`）定位。
- **发送反馈按钮灰着点不动** —— 昵称改为可选，不填以「匿名作者」发出。
- **文件工具写不进共享工作区** —— 会话工作目录现在跟着你选的文件夹，而不是 App 私有目录。
- `computer_*` 工具在安卓上不再占位；`reasonix-session-tmp-*` 残留不再累积。

> 如果你装的是 1.2.1 或更早，请换 1.2.2。

## 安装

1. 下载最新版本的 APK（见 Releases）。
2. 在系统设置里允许安装来自此来源的应用。
3. 打开 APK 安装。首次启动会在本机解包界面并拉起内核，随后进入设置向导。

支持的 ABI：`arm64-v8a`（主流机型）。最低系统版本 Android 8.0。

## 第一次使用

1. 打开应用，按向导添加一个模型来源（填入接口地址与 API Key）。
2. 需要连服务器时，进入「设置 → 远程」，添加一台机器（地址、端口、用户、私钥）。
3. 连接成功后，该机器的工作区会与本地工作区并列显示，可直接在其上发任务。
