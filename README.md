# Reasonix Mobile (Android)

把电脑版 [Reasonix](https://github.com/esengine/DeepSeek-Reasonix) 装进手机。

> **与上游的关系**
>
> Reasonix 本体（内核与界面）是上游项目
> [`esengine/DeepSeek-Reasonix`](https://github.com/esengine/DeepSeek-Reasonix) 的作品，
> 版权归 `Copyright (c) 2026 Reasonix Contributors`，以 MIT 许可发布 ——
> 本仓库的 [LICENSE](LICENSE) 即上游原文，未作改动。
>
> 本仓库只做安卓侧的封装：把内核与页面打进 APK，补上移动端布局与安卓特有的接线。
> **它不是上游项目，也不代表上游**，不含对上游代码的重新授权。

## 为什么有这个仓库

上游只提供桌面版。想在手机上随时开一段任务、或者把手机当成随身的工作区，
得把内核和界面一起打包成一个能直接安装的安卓应用 —— 这个仓库做的就是这件事。

它不改上游的功能与授权，只补三样桌面版不需要、手机必需的东西：

- **移动端布局**：窄屏下的侧栏、工作台、设置页与安全区适配。
- **安卓特有的接线**：剪贴板、文件选择、系统返回键、输入法避让、DNS 读取等，
  这些在桌面浏览器里由系统代劳，在 WebView 里要靠壳层补齐。
- **随包自带的运行时**：内核交叉编译成 `arm64-v8a` 并随包分发，装完即可离线启动。

## 这是什么

需要算力或要动文件时，通过内置的远程连接把它指向你自己的服务器，命令在服务器上执行。

- **本机运行**：应用内自带内核与界面，离线也能启动，不需要额外装一个后台服务。
- **自带远程连接**：内置 SSH，可添加并管理多台服务器，在其上打开工作区、跑任务，
  界面仍在本机。首次连接会在目标机器上引导一个常驻实例。
- **局域网配对**：手机扫电脑上的二维码即可接管那台电脑的会话；扫过一次的电脑会记
  在菜单里，下次点一下就能重连，不用再扫。反过来，电脑也能扫码连上手机上的内核。
- **内置浏览器**：页面由应用自带的 WebView 渲染，禁止嵌入的站点也能打开，
  模型可以读正文、执行脚本、点击页内元素。
- **隐私**：对话、代码与 API Key 都保存在本机应用目录内，不上传。

## 安装

1. 下载最新版本的 APK（见 [Releases](https://github.com/imcreazy/DeepSeek-Reasonix-Mobile-APK/releases)）。
2. 在系统设置里允许安装来自此来源的应用。
3. 打开 APK 安装。首次启动会在本机解包界面并拉起内核，随后进入设置向导。

支持的 ABI：`arm64-v8a`（主流机型）。最低系统版本 Android 8.0。鸿蒙（卓易通）也可安装。

> 正式包用的是本仓库固定的签名密钥。若系统提示「未知来源」，一路允许即可；
> 若提示「签名不一致」，说明机器上装着同名的其他应用，需要先卸载它再装。

## 第一次使用

1. 打开应用，按向导添加一个模型来源（填入接口地址与 API Key）。
2. 需要连服务器时，进入「设置 → 远程」，添加一台机器（地址、端口、用户、私钥）。
3. 连接成功后，该机器的工作区会与本地工作区并列显示，可直接在其上发任务。

## 更新记录

### 1.3.1

- **打开网页失败后，再打开别的网页会返回上一次的旧错误**：失败状态跨导航残留，而且把「页面还没到」当成了页面本身。现在每次导航都会重新等它落定，只看当前实际页面；「刷新」重试的是失败的那个地址，不再是错误页自己。
- **点不了、填不了**：手机版浏览器此前不产生元素编号，点按、填写、下拉选择、滚动都做不了。现在快照会给能操作的元素编号（如 `[e3]`），按编号即可操作。
- **`new_tab` 没反应也没提示**：手机只有一个浏览页面，现在会在返回里说明一次。
- **页面请求列表永远为空**：现在会列出页面实际请求的资源，并注明响应内容在本机拿不到。
- **网页打不开只剩英文错误码**：现在按原因显示中文；内核的语言也改为跟随系统。

### 1.3.0

- **加号加附件，多选后一个都没加进去**（只选一个才行）：系统选择器返回多选时，结果放在「多项」字段里，而壳层读的是单文件字段，于是多选读出来等于什么都没选。现在先读多项、再回退单文件，并去掉重复项。
- **窄屏下用浏览器会抢占整屏、把对话盖住**：以前一开始操作浏览器，界面就自动把浏览器面板推到前面；手机太窄，那等于把回答整个盖住。现在窄屏改为在对话上方给一条提示（「模型正在使用浏览器 · 查看 / 知道了」），点了才打开；宽屏仍然自动在右侧显示、不挡对话。
- **网页加载失败只说英文错误页**：浏览器的错误页本身也是一次加载，把刚报出去的失败状态清掉了；读页面时又把错误页的文字当成站点正文抽了回来。现在壳层会认出错误页并把原因交给内核，界面按原因显示中文。
- **地址栏与标题跟实际页面对不上**：页面读完新地址后没有通知界面刷新，界面停在旧值上。现在地址或标题一变化就会通知。
- **新增设置项**：设置 → 内置浏览器 →「agent 打开网页时自动显示」，默认跟着屏幕宽度走。

### 1.2.4

- **文件工具写不进选定的共享工作区**：会话的工作目录由壳层设定，而内核判断「能写到哪」是从工作目录自己推的，手机上两者没对上。这一版把工作目录明说给内核（内核新增 `--dir`），不再靠推断。
- **内置浏览器打不开**（报 `connection refused`）：服务起来了、端口也分配了，但它绑在 IPv6 的 `::1`，而内核连的是 IPv4 的 `127.0.0.1`。现在两边都明确用 `127.0.0.1`。
- **设置 → 网络里的 `dns` / `doh` 在配置文件里找不到**：这两项的注释示例只写在全新生成的配置里，升级上来的配置保存时不会补。现在保存过网络设置就会补进 `[network]` 段。
- 顺带修掉同一处的两个问题：内核先开网页、界面后打开浏览器面板时不再失败；工作目录选错时不再静默退回，会记下原因。

### 1.2.3

- **对话框右上角的「tokens」文字去掉**：只留上下箭头与数字；「估算中」的 `≈` 移到数字前，信息不丢。
- **模型来源的名称可以写中文**：显示名与配置名分离，界面照你写的显示，配置里自动派生一个 ASCII 名（`公司中转站` → `relay`）。
- **探测失败不再显示一串原始 JSON**：那串 JSON 是内核协议原文，现在按错误码显示中文句子。
- **设置 → 模型服务页的输入框不再被键盘挡住**。
- **新增内置浏览器**：以前的浏览器面板用内嵌框架，禁止嵌入的站点打不开；现在改用应用自带的 WebView 渲染，这类站点能打开，模型也能读正文、执行脚本、点击页内元素。用严格中转站时，无参数工具调用不再返回 HTTP 400。
- 内部还修了三个问题：本机浏览器接口原本没有认证（同机任意应用可调用 `/eval`），现已加每次启动生成的随机密钥；加载失败提示会被随后的一次「加载完成」抹掉；页面侧一项静态检查被前两版的改动弄破，现已补登记。

### 1.2.2

- **每个「复制」按钮都说复制失败**：安卓 WebView 里页面拿不到剪贴板权限，改走壳层的剪贴板桥。
- **长按文件有时弹菜单、有时变成选文字**：文件行不再可选中，系统的文本选择菜单不再抢长按。
- **「导出到下载」点不动**、**导出 `.md` 变成 `.md.txt`**：前者是布局把按钮盖住了；后者是写文件时声明成 `text/plain` 与 `.md` 不符。
- **加号上传附件默认打开的不是「最近」**：1.2.0 起多传了一个「去最近」的参数，而那个目录在系统里并不存在。系统默认落点本来就是「最近」，去掉该参数即可。
- 底部报错条的「知道了」点不到；键盘弹着时工作区菜单跑到右上角；发送反馈按钮因要求填昵称而灰着点不动。
- 文件工具写不进共享工作区；`computer_*` 工具在安卓上不再占位；`reasonix-session-tmp-*` 残留不再累积。

### 1.2.1

修复「新建工作区」：两处可选方法名对不上，一处让权限检查被整段跳过（所以不弹权限提示），一处把手机误判成没有文件夹选择器。现在点侧栏加号会正常弹出系统文件夹选择器。

### 1.2.0

- **新建工作区**：侧栏「这台机器」后面的加号可以直接打开手机上的文件夹作为工作区（首次需在系统设置里授予「所有文件访问」，该权限没有弹窗，应用会跳到对应页面）。
- **对话框内的工作区切换器**：状态行右侧可直接换文件夹或新建。
- **自定义 DNS / DNS over HTTPS**：设置 → 网络里可指定解析器，用于绕开域名解析被篡改的环境。
- **运行中不熄屏**，并会请求电池优化豁免；**恢复上次的项目与会话**。
- 修了输入法遮挡初始设置页输入框、底部报错条点不到、设置面板背景误触等问题。
