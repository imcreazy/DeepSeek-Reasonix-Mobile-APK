## 为什么有这个仓库

上游只提供桌面版。想在手机上随时开一段任务、或者把手机当成随身的工作区，
得把内核和界面一起打包成一个能直接安装的安卓应用 —— 这个仓库做的就是这件事。

它**不改上游的功能与授权**，只补三样桌面版不需要、手机必需的东西：

- **移动端布局**：窄屏下的侧栏、工作台、设置页与安全区适配。
- **安卓特有的接线**：剪贴板、文件选择、系统返回键、输入法避让、DNS 读取等，
  这些在桌面浏览器里由系统代劳，在 WebView 里要靠壳层补齐。
- **随包自带的运行时**：内核交叉编译成 `arm64-v8a` 并随包分发，装完即可离线启动。

## 这是什么

需要算力或要动文件时，通过内置的远程连接把它指向你自己的服务器，命令在服务器上执行。

- **本机运行**：应用内自带内核与界面，离线也能启动，不需要额外装一个后台服务。
- **自带远程连接**：内置 SSH，可添加并管理多台服务器，在其上打开工作区、跑任务，
  界面仍在本机。首次连接会在目标机器上引导一个常驻实例。
- **局域网配对**：手机扫电脑上的二维码即可接管那台电脑的会话；扫过一次的电脑会记
  在菜单里，下次点一下就能重连，不用再扫。反过来，电脑也能扫码连上手机上的内核。
- **内置浏览器**：页面由应用自带的 WebView 渲染，禁止嵌入的站点也能打开，
  模型可以读正文、执行脚本、点击页内元素。
- **隐私**：对话、代码与 API Key 都保存在本机应用目录内，不上传。

## 安装

1. 下载最新版本的 APK（见 [Releases](https://github.com/imcreazy/DeepSeek-Reasonix-Mobile-APK/releases)）。
2. 在系统设置里允许安装来自此来源的应用。
3. 打开 APK 安装。首次启动会在本机解包界面并拉起内核，随后进入设置向导。

支持的 ABI：`arm64-v8a`（主流机型）。最低系统版本 Android 8.0。鸿蒙（卓易通）也可安装。

> 正式包用的是本仓库固定的签名密钥。若系统提示「未知来源」，一路允许即可；
> 若提示「签名不一致」，说明机器上装着同名的其他应用，需要先卸载它再装。

## 第一次使用

1. 打开应用，按向导添加一个模型来源（填入接口地址与 API Key）。
2. 需要连服务器时，进入「设置 → 远程」，添加一台机器（地址、端口、用户、私钥）。
3. 连接成功后，该机器的工作区会与本地工作区并列显示，可直接在其上发任务。
